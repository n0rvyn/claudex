## Decisions

### [DP-001] Task 6 count_tokens 计数路径选择 (blocking)

**Context:** Task 6 `buildCountablePayload` 可选择"复用 IR codec"或"inline minimal conversion"。后者风险是与 bridge 真实 `prepareTurn.initialPayload` 的编码不完全一致，导致端点 count ≠ bridge `messageStartInputTokens`。
**Options:**
- A: Hard-require 复用 `IRAnthropicCodec.decode` → `IRResponsesCodec.encodeFullHistory` 路径 — 保证字节级一致，但耦合 IR 内部
- B: Inline minimal conversion — 简单但必然漂移（tools/instructions 编码细节差异）
- C: A + 新增测试 `endpointMatchesBridgePrepareTurnInitialPayload`（端点 count vs bridge 真实路径 count 必须相等）锁定不漂移
**Recommendation:** C — `IRAnthropicCodec.swift:7` + `IRResponsesCodec.swift:8` 都是 `public enum`，复用路径无可见性障碍；plan 现有"if that surface is private, inline ..." fallback 的前提不成立（grep 证实）。加测试可锁定语义一致性，防止 Phase 5 之后 IR 内部改动导致静默漂移。

### [DP-002] refresh_token rotating 假设验证 (blocking)

**Context:** `SubscriptionSessionLoader` actor 串行化假设"并发双 refresh 幂等"，但 OAuth refresh_token 是否 rotating 影响此假设。
**Options:**
- A: Task 1 probe 明确确认 codex refresh endpoint 是否 rotate refresh_token；若非 rotating，plan 显式声明幂等假设
- B: 无论 probe 结果，Task 4 Step 3 加 cache-hit short-circuit（5s 内复用 cached credentials）— 保守方案
- C: 使用分布式锁 / 更强同步原语（over-engineering）
**Recommendation:** A — 先证据驱动；codex-rs 源码（Task 1 已计划阅读）即可回答。若 probe 显示 rotating，切换到 B；若非 rotating（大多数 OpenAI OAuth 场景），A 是最小改动。Task 1 probe 报告应明确包含此字段。

### [DP-003] MockSessionLoader 类型选择 (recommended)

**Context:** Task 5 Step 4 需要 mutable state（refreshedCredentials、refreshError、call-count），但现有是 struct + let-only。
**Options:**
- A: `final class MockSessionLoader: SubscriptionSessionProviding, @unchecked Sendable` + NSLock 保护 mutable fields
- B: `actor MockSessionLoader` — 所有 20+ call sites 需 await 访问
- C: Struct + external `nonisolated(unsafe) let tracker: AtomicTracker` — 最小改动但混合范型
**Recommendation:** A — 20+ 现有 call sites 不需要改（构造器签名不变；读 `.credentials` 从 struct property 变 class property，Swift 语法相同）；actor 会让所有 test 加 await。NSLock 开销可接受（测试场景）。
