## [S1] 具体候选错误验证

### 断言 1 [C:95] — BLOCKING
**Task 1 的 `TaskLocal` 覆盖不会传播到 HTTP 请求处理任务；daemon 在 `CC_ROUTER_TRACE_PATH` 被设置时仍然写入生产路径。**

证据链：
- `Sources/CCRouterCore/LocalHTTPServer.swift:214-219`：`listener.newConnectionHandler = { [handler] connection in ...; Task.detached { await LocalHTTPServer.serve(...) } }`
- Swift 语言规范：`Task.detached` 显式不继承 enclosing task 的 `@TaskLocal` 值（这是 `detached` 与 `Task.init` 的核心区别；后者会继承）
- `Sources/CCRouterCore/AnthropicBridge.swift:74,98,116,133,226,...`：所有 `await TraceLogger.shared.log(...)` 调用都发生在 handler 执行链路中
- `Sources/CCRouterCore/TraceLogger.swift:25-27`：`effectiveFileURL { Self.overrideFileURL ?? defaultFileURL }` — `overrideFileURL` 此时读到 nil（因为已脱离 wrap），fallback 到 `defaultFileURL = UserHomeResolver.defaultTraceLogFilePath()` 即生产路径

结果：❌ 断言成立 [C:95] → Task 1 的设计在运行时会 **静默失败**，但 plan 的 Verify 步骤（`grep -n "DaemonTraceOverrideResolver"`）会通过，fail-closed 契约（Threat Model Failure modes #1）被违反。

**计划需补充：**
Task 1 必须选择以下其一（由 plan 作者决定，推荐 C）：
- **A**：在 `LocalHTTPServer.serve` 的 detached Task 内重新绑定 TaskLocal — 需要把 URL 从 daemon 传到 `GatewayDaemon`，再传到 `LocalHTTPServer`，在 `newConnectionHandler` 闭包捕获后 `TaskLocal.withValue` 包住 `Task.detached` 体内部（但 `Task.detached` 外层 `withValue` 仍不传播，所以真实写法是 `Task.detached { await TraceLogger.$overrideFileURL.withValue(capturedURL) { await serve(...) } }`）。
- **B**：放弃 TaskLocal 用于 daemon 级覆盖，在 `TraceLogger` 增加一个 non-TaskLocal 静态 override（nonisolated 线程安全如 `Atomic<URL?>` / `OSAllocatedUnfairLock<URL?>`），`effectiveFileURL` 先读静态、再读 TaskLocal、再 fallback；Task 2 的测试用 TaskLocal 仍然工作。
- **C**（推荐）：在 daemon 启动路径不要用 TaskLocal，而是通过 `TraceLogger.init(fileURL:)` 注入自定义 instance（已有 init 接受 `fileURL` 参数），让 `GatewayDaemon` 或 `AnthropicBridge` 接受一个可注入 TraceLogger，替代 `TraceLogger.shared`。（但这是较大重构，对 acceptance-only phase 过重；实际上选 A/B 更合适）
- 额外要求：Task 1 的 Verify 必须加一条**运行时断言**：`env CC_ROUTER_TRACE_PATH=/tmp/phase7-verify-$(date +%s).jsonl $DAEMON_BIN &`，发一条 curl 到 `/v1/messages`，然后 `test -s /tmp/phase7-verify-*.jsonl && !(stat -f '%m' ~/Library/Application\ Support/ModelBridge/trace.jsonl  changed)`。当前 Verify 只 grep resolver 符号，无法捕获此 bug。
